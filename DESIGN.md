# DOTARUX Growth Agency — Design System Specification

## 1. Aesthetic Thesis & Architectural Principles
- **Aesthetic Direction**: High-End Utilitarian Minimalism & Editorial Art Direction (Pentagram / Locomotive / Stripe Press).
- **Core Philosophy**: Zero generic templates, zero AI purple glow, zero drop shadow bloat. Everything is founded on high-contrast typography, mathematical grid alignments, tangible editorial tables, and pure signal-to-noise clarity.
- **Surface**: Architectural Gallery Paper (`#FBFBFA`) and Crisp Pure White (`#FFFFFF`).

## 2. Typographic Hierarchy
| Role | Family | Weight / Style | Tracking | Line Height |
|---|---|---|---|---|
| Editorial Headlines | `Instrument Serif` | 400 / Italic & Regular | `-0.03em` | `1.05` |
| Primary UI & Body | `Plus Jakarta Sans` | 400, 500, 600, 700 | `-0.015em` | `1.55` |
| Technical Tags & Data | `JetBrains Mono` | 400, 500, 700 | `+0.04em` | `1.4` |

## 3. Calibrated Color Palette
- **Canvas Base**: `#FBFBFA` (Warm Museum Bone / Paper)
- **Primary Card Surface**: `#FFFFFF` (Stark White)
- **Subtle Surface**: `#F7F7F5` (Muted Warm Tint)
- **Primary Ink**: `#111111` (Deep Off-Black)
- **Secondary Ink**: `#4B5563` (Neutral Slate Charcoal)
- **Tertiary Ink / Meta**: `#9CA3AF` (Muted Index Gray)
- **Hairline Dividers**: `rgba(0, 0, 0, 0.08)`
- **Accent Signals**:
  - Emerald Conversion Pulse: `#059669` / `#ECFDF5`
  - Deep International Cobalt: `#1D4ED8` / `#EFF6FF`
  - Warm Terroir Amber: `#D97706` / `#FFFBEB`

## 4. Layout Mechanics
- **Grid Structure**: 12-column asymmetric layout with mathematical column spans.
- **Section Rhythm**: Generous vertical breathing room (`py-24` to `py-32`).
- **Interactive Directory**: Clean index table replacing generic rounded cards.
- **Tactile Inputs**: Minimalist border-based text fields with subtle underline feedback.
